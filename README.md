## 🚀 How to Upload to GitHub & Get a Live Website Link (GitHub Pages)

Follow these simple steps to upload your project to GitHub and publish it live on the internet!

### Step 1: Create a GitHub Account & New Repository
1. Go to [GitHub.com](https://github.com) and log in (or sign up for free).
2. Click the **`+`** icon at the top right and select **New repository**.
3. Fill in the details:
   - **Repository name:** `portfolio` (or `rahul-portfolio`)
   - **Description:** `My 1st College Mini Project - Personal Portfolio Website`
   - Set visibility to **Public** (important for free GitHub Pages hosting).
   - Leave other checkboxes unchecked and click **Create repository**.

### Step 2: Upload Files Directly via Browser (Easiest Method)
1. On your new repository page, click the link that says **"uploading an existing file"**.
2. Drag and drop the following from your `d:\rahul_portfolio` folder into GitHub:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
   - The entire `images` folder (containing `rahul_profile.jpg`).
3. Scroll down, type a commit message like `Add portfolio mini project files`, and click **Commit changes**.

### Step 3: Turn on GitHub Pages (Get Your Live Link!)
1. In your GitHub repository, click on the **Settings** tab (gear icon at the top).
2. On the left sidebar menu, click on **Pages** (under the "Code and automation" section).
3. Under **Build and deployment**:
   - **Source:** Select `Deploy from a branch`
   - **Branch:** Click the dropdown and select `main` (or `master`), and keep the folder as `/(root)`.
4. Click **Save**.
5. Wait 1 to 2 minutes, then refresh the page.
6. A notification banner will appear at the top saying:
   > **"Your site is live at https://<your-github-username>.github.io/<repo-name>/"**
   
   🎉 *You can now share this live link with your college professors, classmates, and add it to your resume!*
